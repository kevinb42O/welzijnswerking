# Public Sans

De actuele website gebruikt Public Sans als één variabele sans-serif voor koppen, lopende tekst en bediening. De bestanden worden lokaal geleverd, zonder verzoek naar een externe fontdienst.

- Familie en oorspronkelijke bron: https://github.com/uswds/public-sans
- Distributie: Google Fonts, CSS voor `Public Sans:wght@100..900`, opgehaald op 20 oktober 2026.
- Latin: https://fonts.gstatic.com/s/publicsans/v21/ijwRs572Xtc6ZYQws9YVwnNGfJ7QwOk1.woff2
- Latin Extended: https://fonts.gstatic.com/s/publicsans/v21/ijwRs572Xtc6ZYQws9YVwnNIfJ7QwOk1Fig.woff2
- Licentie: SIL Open Font License 1.1, opgeslagen als `LICENSE-public-sans.txt`; bron https://github.com/google/fonts/blob/main/ofl/publicsans/OFL.txt

`tokens.css` bevat de unicode-bereiken en gewichtreeks 100–900. Alleen het Latin-bestand wordt vooraf geladen. De oude fontbestanden zijn behouden voor historische bronbestanden; de actuele pagina verwijst er niet naar.
